Esse é um projeto bem simples que fiz para meu padrasto, que serviu mais como uma forma de treino. Ele queria uma forma simples e fácil de calcular o saldo total dele após várias despesas. O projeto é uma página que calcula seu saldo final, conforme você adiciona as despesas.

## Funcionamento
Primeiro, você insere um saldo bancário inicial, e pressiona "Enter".

Após isso, você vai adicionando os valores das suas despesas e pressionando novamente "Enter" cada vez, para calcular automaticamente o saldo resultante.
